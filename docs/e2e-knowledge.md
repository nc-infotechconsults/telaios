# Knowledge Base: Planning Constraints

Project codename: SKYLARK.

Mandatory implementation constraints:
- Backend framework: FastAPI.
- Frontend framework: React + TypeScript.
- Authentication requirement: OAuth2 Device Authorization Grant (device flow).
- Performance requirement: p95 API latency under 200ms for authenticated read endpoints.
- Security requirement: secrets must never be committed; use environment variables only.

Delivery requirement:
- Build a first milestone plan with repositories, documents ingestion, and task execution readiness.
