# HeroUI v3 Migration — Slice 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install HeroUI v3 in the frontend, upgrade React 18 → 19, wire HeroUI's theme to the existing `brand_color` setting via `--accent`, swap the toast package, and rewrite `Login.tsx` as the smoke test. Every other page must keep rendering exactly as today via a legacy `@theme inline` token bridge.

**Architecture:** Two visual systems coexist during the migration: HeroUI v3 on `Login.tsx` (HeroUI primitives, no inline styles), and the existing glass design system everywhere else. A small `@theme inline` block in `index.css` maps the v2-style Tailwind tokens that 77 unmigrated files use (`bg-primary`, `bg-content1`, `text-default-400`, `bg-default-50/40`, `border-divider`) onto HeroUI v3 tokens (`--accent`, `--surface`, `--default`, `--separator`), with synthetic scale steps computed via `color-mix`. The `applyAppSettingsToDocument` bridge keeps emitting every glass var it emits today, and additionally emits HeroUI's `--accent` and `--accent-foreground` from `brand_color`.

**Tech Stack:** React 19, Vite, Tailwind CSS v4, `@heroui/react@^3`, `@heroui/styles@^3`, `react-router-dom@^6.26`, `framer-motion@^11`, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-06-07-heroui-v3-migration-slice-1-foundation-design.md`

- [ ] **Step 1: Full file replacement** of `frontend/src/pages/Login.tsx`:

  ```tsx
  import { useState } from "react";
  import { useNavigate } from "react-router-dom";
  import { Button, Card, FieldError, Form, Input, Label, TextField } from "@heroui/react";
  import { useAuth } from "../context/AuthContext";
  import { TelaiOSLogo } from "../components/common/TelaiOSLogo";

  export default function Login() {
    const { login } = useAuth();
    const navigate = useNavigate();
    const [email, setEmail] = useState("");
    const [password, setPassword] = useState("");
    const [error, setError] = useState("");
    const [loading, setLoading] = useState(false);

    async function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
      e.preventDefault();
      setError("");
      setLoading(true);
      try {
        await login(email, password);
        navigate("/");
      } catch {
        setError("Invalid email or password.");
      } finally {
        setLoading(false);
      }
    }

    return (
      <main className="min-h-screen flex items-center justify-center bg-background text-foreground p-4">
        <Card className="w-full max-w-sm">
          <Card.Content className="p-8">
            <div className="flex items-center justify-center gap-2.5 mb-7">
              <TelaiOSLogo size={36} />
              <span className="text-[22px] font-bold tracking-tight">TelaiOS</span>
            </div>
            <Form onSubmit={handleSubmit} className="flex flex-col gap-4">
              <TextField
                isRequired
                name="email"
                type="email"
                value={email}
                onChange={setEmail}
              >
                <Label>Email Address</Label>
                <Input autoComplete="email" placeholder="you@example.com" />
                <FieldError />
              </TextField>
              <TextField
                isRequired
                name="password"
                type="password"
                value={password}
                onChange={setPassword}
                isInvalid={!!error}
              >
                <Label>Password</Label>
                <Input autoComplete="current-password" placeholder="••••••••" />
                {error && <FieldError>{error}</FieldError>}
              </TextField>
              <Button type="submit" isPending={loading} fullWidth>
                {loading ? "Signing in…" : "Sign in"}
              </Button>
            </Form>
          </Card.Content>
        </Card>
      </main>
    );
  }
  ```

  Key choices:

  - `<TelaiOSLogo>` keeps as-is (SVG component).

  - `<Card.Content className="p-8">` for inner padding.
  - `<TextField>` + `<Label>` + `<Input>` + `<FieldError>` is HeroUI v3's idiomatic field anatomy (React-Aria-driven).
  - `<Button type="submit" isPending={loading} fullWidth>` — default variant uses `--accent` (i.e., the brand color from settings).
  - No glass CSS classes, no inline styles, no `apple-input` class.
