## How to read this document

- Tasks are numbered `<phase>.<task>` and intended to be executed **strictly sequentially** by a single agent session (Sonnet 4.6).
- Each task lists: **action**, **target path(s) in `server/`**, **source path(s) being ported**, **verification step**.
- After each phase, run the **phase checkpoint** before moving on.
- "Port" = rewrite functionally-equivalent Python; not a literal translation. Behaviour parity matters; line-by-line parity does not.
- All paths under `server/src/telaios/` unless otherwise noted; tests live under `server/tests/`.
